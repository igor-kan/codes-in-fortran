# Composite Simpson 1/3 High-Order Quadrature (`simpson_quadrature_d56`)

> Category: **Numerical Integration** | Language: **Fortran 2008**

## Overview

Evaluates 1D definite integrals of sampled function arrays or cubic polynomials exactly to machine precision using composite 1-4-2 Simpson weights.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Integrates polynomials up to degree 3 exactly on any even-interval grid.
