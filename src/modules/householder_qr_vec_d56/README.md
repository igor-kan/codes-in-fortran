# Householder Orthogonal Reflector Vector Annihilator (`householder_qr_vec_d56`)

> Category: **Orthogonal Transformations** | Language: **Fortran 2008**

## Overview

Constructs unit Householder reflectors H = I - 2*v*v^T aligning input vectors cleanly along the first canonical basis axis while preserving L2 norm.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Reflected vector satisfies ||Hx||_2 == ||x||_2 and zero trailing components.
